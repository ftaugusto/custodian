Example policy — PowerVS public network interface (tag → stop → delete)

policies:
  - name: powervs-instance-public-network-tag
    description: |
      MUST — PowerVS instances with a public network interface (pub-vlan or
      external IP). Tags the instance workspace for operator review.
    resource: ibm.powervs-instance
    filters:
      - type: public-network-interface
    actions:
      - type: tag
        tags:
          custodian-review: "public-network-interface"

  - name: powervs-instance-public-network-stop
    description: |
      MUST — Stop active PowerVS instances with a public network interface.
    resource: ibm.powervs-instance
    filters:
      - type: public-network-interface
      - type: value
        key: status
        op: eq
        value: ACTIVE
    actions:
      - stop

  - name: powervs-instance-public-network-delete
    description: |
      MUST — Delete stopped + reviewed PowerVS instances with a public network.
    resource: ibm.powervs-instance
    filters:
      - type: public-network-interface
      - type: value
        key: status
        op: eq
        value: SHUTOFF
      - type: tag
        key: custodian-review
        op: eq
        value: "public-network-interface"
    actions:
      - delete

Installation

pip install c7n
pip install -e tools/c7n_ibmcloud

Required environment variables:

export IBMCLOUD_API_KEY="<your-api-key>"
export IBMCLOUD_REGION="us-south"
export IBMCLOUD_ACCOUNT_ID="<your-account-id>"

Run a policy file:

custodian run \
  --configs tools/c7n_ibmcloud/policies/vpc-networking.yaml \
  --output-dir /tmp/c7n-out \
  --cache-period 0

Run all policies:

custodian run \
  --configs tools/c7n_ibmcloud/policies/ \
  --output-dir /tmp/c7n-out \
  --cache-period 300

cd cloud-custodian
python3 -m pytest tools/c7n_ibmcloud/tests/ -v

Real-time operation

For near-real-time enforcement (latency ~1 min from API call to remediation), combine two layers:

  1. Event-triggered runs — Route IBM Cloud Activity Tracker audit events through IBM Cloud Event Notifications to a Code Engine job that runs custodian run --cache-period 0 scoped to the affected resource type.
  2. Scheduled sweep — A Code Engine scheduled job running every 15 minutes catches any events missed by the trigger pipeline.
