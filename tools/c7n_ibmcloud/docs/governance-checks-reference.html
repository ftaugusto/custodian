IBM Cloud Custodian — Governance Checks Reference

Complete catalogue of checks for every resource type covered by c7n_ibmcloud — IAM, VPC, COS, KMS, IKS, PowerVS, and DBaaS.

Runtime Error Handling

All IBMBaseAction.process() calls handle API errors gracefully per resource — a single failure never aborts the full policy run.

ConditionLog levelTriggerBehaviour
Resource already deleted (race condition)DEBUGApiException code=404, HTTPError status=404, NoSuchBucket, string "not found"Silent skip — continues to next resource. No traceback.
Permission deniedWARNINGApiException code=401/403, ClientError AccessDenied, string "(403)"Warning logged with resource ID and exception. Continues. No traceback.
Unexpected errorERRORAny other exceptionFull traceback via log.exception. Continues unless fail_on_error: true.
fail_on_error: true setas aboveAny exceptionRe-raises after logging — aborts remaining resources in the batch.
